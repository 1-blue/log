안녕하세요, 블루예요! Next.js App Router는 개발 생산성과 성능을 크게 향상시켰지만, 전통적인 SEO 및 PWA 설정 방식과는 다른 접근이 필요해요.<br />
특히 `generateMetadata`와 `generateViewport` 함수는 App Router 환경에서 웹사이트의 검색 엔진 노출과 사용자 경험을 결정하는 핵심 요소인데요.<br />
오늘은 이 두 함수를 실무에서 어떻게 효과적으로 활용하여 SEO 점수를 높이고, PWA 기능을 강화할 수 있는지 심도 있게 다뤄보려고 해요.

## 🤔 `generateMetadata`와 `generateViewport`의 중요성
### 0️⃣ 왜 이 기능들이 필수적인가요?
웹사이트의 성공은 단순히 기능 구현을 넘어, 검색 엔진에서 잘 노출되고 사용자들이 편리하게 이용할 수 있는지에 달려있어요.<br />
`generateMetadata`는 웹페이지의 제목, 설명, 키워드, Open Graph 이미지 등 SEO의 핵심 요소들을 동적으로 설정할 수 있게 해주고요.<br />
이를 통해 검색 결과에서 더 매력적으로 보이고, 소셜 미디어 공유 시 풍부한 미리보기를 제공할 수 있답니다.<br />
`generateViewport`는 모바일 기기에서의 반응형 동작, PWA 설치 시 앱 아이콘 색상 등 사용자 경험에 직접적인 영향을 주는 뷰포트 관련 설정을 담당해요.<br />
이 두 함수를 잘 활용하면 웹사이트의 접근성과 사용자 친화성을 크게 향상시킬 수 있어요.

### 1️⃣ 기존 방식의 한계와 App Router의 변화
Pages Router 시절에는 `_document.js`나 각 페이지의 `Head` 컴포넌트를 사용하여 메타태그를 관리했어요.<br />
이는 정적인 페이지에서는 문제가 없었지만, 동적인 데이터에 따라 메타태그를 변경해야 할 때 복잡한 로직이 필요했죠.<br />
또한, 서버 사이드 렌더링(SSR) 환경에서 메타태그가 제대로 주입되는지 확인하는 것도 쉽지 않았어요.<br />
App Router에서는 `generateMetadata`와 `generateViewport`가 Server Component에서 실행되기 때문에, 데이터 페칭과 메타데이터 생성을 한 곳에서 처리할 수 있게 되었어요.<br />
이는 개발 편의성을 높이고, SEO 봇이 페이지를 크롤링할 때 항상 최신 정보를 제공할 수 있게 해준답니다.

## ⚙️ `generateMetadata` 심화 활용 전략
`generateMetadata`는 `layout.tsx`나 `page.tsx` 파일에서 비동기 함수로 정의하여 사용할 수 있어요.<br />
부모 레이아웃에서 정의된 메타데이터는 자식 라우트에서 상속받거나 오버라이딩할 수 있어서 유연한 관리가 가능해요.

### 0️⃣ 기본 사용법과 정적/동적 메타데이터
가장 기본적인 사용법은 객체를 반환하는 방식이에요.<br />
정적인 메타데이터는 단순히 객체를 내보내면 되고요, 동적인 데이터가 필요할 때는 `params`나 `searchParams`를 인자로 받아 사용할 수 있어요.<br />
```tsx showLineNumbers {1-10}
// app/layout.tsx 또는 app/page.tsx
import { Metadata } from 'next';

export const metadata: Metadata = {
  title: '블루의 기술 블로그',
  description: '시니어 풀스택 개발자 블루의 실전 기술 블로그입니다.',
  keywords: ['Next.js', 'React', 'TypeScript', 'SEO', '웹 개발'],
  authors: [{ name: '블루', url: 'https://blue.dev' }],
  creator: '블루',
};

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ko">
      <body>{children}</body>
    </html>
  );
}
```
<br />
동적인 메타데이터는 다음과 같이 `generateMetadata` 함수를 사용해요.<br />
```tsx showLineNumbers {1-19}
// app/posts/[slug]/page.tsx
import { Metadata } from 'next';

type Props = {
  params: { slug: string };
  searchParams: { [key: string]: string | string[] | undefined };
};

// 동적 데이터 기반 메타데이터 생성
export async function generateMetadata(
  { params, searchParams }: Props,
): Promise<Metadata> {
  const product = await getProductBySlug(params.slug); // 가상의 데이터 페칭 함수
  if (!product) {
    return { title: '페이지를 찾을 수 없어요.' };
  }

  return {
    title: product.name,
    description: product.description.substring(0, 150) + '...',
    openGraph: {
      images: [product.imageUrl],
    },
  };
}

export default function PostPage({ params }: Props) {
  return <h1>{params.slug} 포스트 내용이에요.</h1>;
}

async function getProductBySlug(slug: string) {
  // 실제 데이터베이스 또는 API 호출 로직
  return {
    name: `Next.js ${slug} 심화 가이드`,
    description: `이것은 ${slug}에 대한 심도 있는 가이드 내용입니다. Next.js 개발자들이 알아야 할 모든 것을 담았어요.`,
    imageUrl: `https://blue.dev/images/${slug}.jpg`,
  };
}
```
<br />
이렇게 `generateMetadata` 함수는 데이터를 비동기적으로 가져와서 페이지 내용에 맞는 메타데이터를 유연하게 생성할 수 있게 해줘요.

### 1️⃣ Open Graph, Twitter Card 등 소셜 공유 최적화
소셜 미디어 공유 시 웹사이트 링크의 미리보기를 풍부하게 보여주는 것은 사용자 유입에 매우 중요해요.<br />
`openGraph`와 `twitter` 속성을 활용하여 제목, 설명, 이미지, URL 등을 상세하게 설정할 수 있어요.
```tsx showLineNumbers {8-22}
// app/posts/[slug]/page.tsx (generateMetadata 함수 내부)
import { Metadata } from 'next';

export async function generateMetadata({ params }: { params: { slug: string } }): Promise<Metadata> {
  const post = await getPostData(params.slug); // 가상의 포스트 데이터 페칭
  if (!post) return { title: 'Post Not Found' };

  return {
    title: post.title,
    description: post.summary,
    openGraph: {
      title: post.title,
      description: post.summary,
      url: `https://blue.dev/posts/${params.slug}`,
      siteName: '블루의 기술 블로그',
      images: [
        {
          url: post.thumbnailUrl,
          width: 1200,
          height: 630,
          alt: post.title,
        },
      ],
      locale: 'ko_KR',
      type: 'article',
    },
    twitter: {
      card: 'summary_large_image',
      title: post.title,
      description: post.summary,
      creator: '@blue_dev',
      images: [post.thumbnailUrl],
    },
  };
}
// ... (나머지 코드)
async function getPostData(slug: string) {
  return {
    title: `Next.js ${slug} 심화 가이드`,
    summary: `이것은 ${slug}에 대한 심도 있는 가이드 내용입니다. Next.js 개발자들이 알아야 할 모든 것을 담았어요.`,
    thumbnailUrl: `https://blue.dev/images/${slug}-og.jpg`,
  };
}
```
<br />
`images` 속성은 배열 형태로 여러 이미지를 지정할 수 있으며, 각 이미지에 `width`, `height`, `alt` 속성을 부여하여 상세 정보를 제공할 수 있어요.<br />
특히 `summary_large_image` 타입의 Twitter Card는 큰 이미지를 보여주므로 클릭률을 높이는 데 효과적이에요.

### 2️⃣ `alternates`로 다국어 및 캐노니컬 설정
다국어 웹사이트를 운영하거나, 동일한 콘텐츠가 여러 URL로 접근 가능한 경우 `alternates` 속성이 중요해요.<br />
이는 검색 엔진에 어떤 URL이 해당 콘텐츠의 "정식" 버전인지, 또는 어떤 언어 버전을 제공하는지 알려줘요.
```tsx showLineNumbers {8-16}
// app/products/[id]/page.tsx (generateMetadata 함수 내부)
import { Metadata } from 'next';

export async function generateMetadata({ params }: { params: { id: string } }): Promise<Metadata> {
  const product = await getProductData(params.id);
  if (!product) return { title: 'Product Not Found' };

  return {
    title: product.name,
    description: product.description,
    alternates: {
      canonical: `https://blue.dev/products/${params.id}`, // 정식 URL 지정
      languages: {
        'en-US': `https://blue.dev/en-US/products/${params.id}`,
        'ja-JP': `https://blue.dev/ja-JP/products/${params.id}`,
        'x-default': `https://blue.dev/products/${params.id}`, // 기본 언어
      },
    },
  };
}
// ... (나머지 코드)
async function getProductData(id: string) {
  return {
    name: `블루의 프리미엄 상품 ${id}`,
    description: `이 상품은 ${id}번 상품으로, 최고의 품질을 자랑해요.`,
  };
}
```
<br />
`canonical`은 중복 콘텐츠 문제를 해결하고 SEO 점수를 올리는 데 필수적이고요.<br />
`languages`는 다국어 버전이 있는 경우 검색 엔진이 사용자 언어에 맞는 페이지를 제공하도록 돕는 역할을 해요.

### 3️⃣ 상속 및 오버라이딩 원리 이해
`generateMetadata`는 계층적으로 동작해요.<br />
`app/layout.tsx`에서 정의된 `metadata`는 모든 하위 라우트에 상속돼요.<br />
그리고 하위 라우트(`app/blog/layout.tsx`나 `app/blog/posts/[slug]/page.tsx`)에서 `generateMetadata`를 정의하면, 부모의 메타데이터를 확장하거나 특정 속성을 오버라이딩할 수 있어요.<br />
이때, 객체 병합(Object Merge) 방식으로 동작하며, 자식에서 정의된 속성이 부모의 속성을 덮어씌우는 방식이에요.<br />
예를 들어, `layout.tsx`에 `title`이 정의되어 있고, `page.tsx`에도 `title`이 정의되어 있다면 `page.tsx`의 `title`이 최종적으로 적용된답니다.<br />
하지만 `openGraph.images` 같은 배열 타입은 기본적으로 병합되지 않고 덮어씌워지므로 주의해야 해요.<br />
Next.js 14부터는 `metadata.template`을 사용하여 상속된 `title`에 접두사/접미사를 쉽게 추가할 수 있어요.<br />
```tsx showLineNumbers {4,8}
// app/layout.tsx
export const metadata = {
  title: {
    template: '%s | 블루의 블로그', // 자식 페이지의 title이 %s에 들어와요.
    default: '블루의 기술 블로그', // title이 없는 페이지의 기본값
  },
  description: '블루의 기술 블로그입니다.',
};

// app/posts/[slug]/page.tsx
export async function generateMetadata({ params }: { params: { slug: string } }) {
  const post = await getPostData(params.slug);
  return {
    title: post.title, // 'Next.js 심화 가이드 | 블루의 블로그'로 렌더링돼요.
  };
}
// ...
```
<br />
이렇게 `template`을 활용하면 모든 페이지에 일관된 제목 형식을 유지하면서도 동적인 제목을 설정할 수 있어요.

## 🚀 `generateViewport`로 PWA 및 반응형 웹 최적화
`generateViewport` 함수는 `viewport` 메타태그와 관련된 설정을 처리하며, 주로 모바일 환경과 PWA 경험에 영향을 줘요.<br />
이 함수도 `generateMetadata`와 유사하게 `layout.tsx`나 `page.tsx`에서 정의할 수 있어요.

### 0️⃣ `viewport` 메타태그의 역할
`viewport` 메타태그는 웹페이지가 다양한 기기에서 어떻게 렌더링될지를 브라우저에 알려주는 역할을 해요.<br />
모바일 환경에서 웹페이지가 축소되지 않고 반응형으로 올바르게 표시되도록 하는 데 필수적이죠.<br />
예를 들어, `width=device-width, initial-scale=1.0`은 기기 너비에 맞춰 페이지 너비를 설정하고 초기 확대/축소 비율을 1.0으로 지정하는 가장 일반적인 설정이에요.

### 1️⃣ 다크 모드, 테마 색상 등 고급 설정
`generateViewport`를 사용하면 PWA의 설치 배너, 주소 표시줄 색상 등 사용자 경험을 향상시키는 다양한 설정을 할 수 있어요.<br />
```tsx showLineNumbers {1-16}
// app/layout.tsx
import { Viewport } from 'next';

export const viewport: Viewport = {
  width: 'device-width',
  initialScale: 1,
  maximumScale: 1,
  userScalable: false, // 사용자의 확대/축소 비활성화 (선택 사항)
  themeColor: '#0070f3', // PWA 테마 색상 (앱 바 색상 등)
  colorScheme: 'dark light', // 다크/라이트 모드 지원
};

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ko">
      <body>{children}</body>
    </html>
  );
}
```
<br />
여기서 `themeColor`는 PWA가 설치될 때 앱의 기본 색상을 지정하고, 모바일 브라우저의 주소 표시줄 색상에도 영향을 줄 수 있어요.<br />
`colorScheme: 'dark light'`는 웹사이트가 다크 모드와 라이트 모드를 모두 지원함을 브라우저에 알려주어, 사용자 기기의 설정에 따라 적절한 모드를 적용할 수 있도록 돕는답니다.

## 🧪 실전 코드 예시
이번 섹션에서는 실제 프로젝트에서 `generateMetadata`와 `generateViewport`를 어떻게 조합하여 사용하는지 보여드릴게요.

### 0️⃣ 레이아웃에서 공통 메타데이터 설정
먼저, `app/layout.tsx`에서 웹사이트 전반에 걸쳐 적용될 기본 메타데이터와 뷰포트 설정을 정의해요.<br />
이는 모든 페이지에 공통적으로 적용되는 SEO 기본값과 PWA 테마를 설정하는 데 유용해요.
```tsx showLineNumbers {1-32}
// app/layout.tsx
import { Metadata, Viewport } from 'next';
import './globals.css'; // 전역 스타일시트

export const metadata: Metadata = {
  metadataBase: new URL('https://blue.dev'), // 정식 도메인 설정
  title: {
    template: '%s | 블루의 개발 블로그',
    default: '블루의 개발 블로그: 실전 웹 개발 가이드',
  },
  description: '시니어 풀스택 개발자 블루가 공유하는 Next.js, React, TypeScript, 웹 성능 최적화 노하우.',
  keywords: ['Next.js', 'React', 'TypeScript', '웹 개발', 'SEO', 'PWA', '프론트엔드'],
  openGraph: {
    title: '블루의 개발 블로그',
    description: '시니어 풀스택 개발자 블루가 공유하는 Next.js, React, TypeScript, 웹 성능 최적화 노하우.',
    url: 'https://blue.dev',
    siteName: '블루의 개발 블로그',
    images: [
      {
        url: 'https://blue.dev/og-image.jpg', // 기본 OG 이미지
        width: 1200,
        height: 630,
        alt: '블루의 개발 블로그',
      },
    ],
    locale: 'ko_KR',
    type: 'website',
  },
  twitter: {
    card: 'summary_large_image',
    title: '블루의 개발 블로그',
    description: '시니어 풀스택 개발자 블루가 공유하는 Next.js, React, TypeScript, 웹 성능 최적화 노하우.',
    images: ['https://blue.dev/twitter-image.jpg'],
    creator: '@blue_dev',
  },
};

export const viewport: Viewport = {
  width: 'device-width',
  initialScale: 1,
  themeColor: '#1a202c', // 다크한 테마 색상

export default function RootLayout({ children }: { children: React.ReactNode }) {

    <html lang="ko">

```
<br />
`metadataBase`를 설정하면 모든 상대 경로 URL(예: `images` 속성)이 이 기본 URL을 기준으로 해석되어 SEO에 유리해요.<br />
`title.template`과 `title.default`를 사용하면 페이지 제목 관리가 훨씬 편리해진답니다.

### 1️⃣ 페이지에서 동적 메타데이터 오버라이딩
이제 특정 포스트 페이지에서 동적인 데이터를 기반으로 메타데이터를 오버라이딩하는 예시를 볼게요.<br />
`generateMetadata` 함수는 비동기로 동작하며, 페이지 컴포넌트와 동일하게 `params`를 받을 수 있어요.
```tsx showLineNumbers {1-34}
// app/blog/[slug]/page.tsx
import { Metadata } from 'next';

type PostPageProps = {
  params: { slug: string };
};

// 가상의 포스트 데이터를 가져오는 함수
async function getPostData(slug: string) {
  // 실제 API 호출 또는 DB 쿼리 로직이 들어갈 곳이에요.
  // 여기서는 예시를 위해 더미 데이터를 반환해요。
  await new Promise(resolve => setTimeout(resolve, 100)); // 비동기 작업 시뮬레이션
  return {
    id: slug,
    title: `Next.js App Router의 ${slug} 완벽 가이드`,
    content: `이것은 ${slug}에 대한 매우 상세한 내용입니다. 개발자들이 궁금해하는 모든 것을 담았어요.`,
    description: `Next.js App Router에서 ${slug}를 효과적으로 사용하는 방법을 배워보세요.`,
    imageUrl: `https://blue.dev/blog/${slug}-hero.jpg`,
    publishedDate: '2026-05-22',
  };
}

export async function generateMetadata(
  { params }: PostPageProps,
): Promise<Metadata> {
  const post = await getPostData(params.slug);

  return {
    title: post.title, // 'Next.js App Router의 [slug] 완벽 가이드 | 블루의 개발 블로그'로 렌더링
    description: post.description,
    openGraph: {
      images: [post.imageUrl], // 새로운 OG 이미지로 오버라이딩
    },
  };
}

export default async function PostPage({ params }: PostPageProps) {
  const post = await getPostData(params.slug); // 페이지 컴포넌트에서도 데이터를 사용해요。

  return (
    <article>
      <h1>{post.title}</h1>
      <img src={post.imageUrl} alt={post.title} style={{ maxWidth: '100%', height: 'auto' }} />
      <p>{post.content}</p>
      <small>게시일: {post.publishedDate}</small>
    </article>
  );
}
```
<br />
여기서 `generateMetadata` 함수는 `post` 데이터를 비동기로 가져와서 페이지 제목, 설명, Open Graph 이미지를 동적으로 설정하고 있어요.<br />
`layout.tsx`에서 정의된 `title.template` 덕분에 `post.title`만 지정해도 최종 제목은 "Next.js App Router의 [slug] 완벽 가이드 | 블루의 개발 블로그"와 같이 자동으로 완성돼요.<br />
`openGraph.images`는 배열이므로, `layout.tsx`의 기본 이미지를 이 페이지의 특정 이미지로 덮어씌우게 된답니다.

## 📝 정리
### 0️⃣ 핵심 요약 및 활용 팁
오늘은 Next.js App Router에서 `generateMetadata`와 `generateViewport`를 활용하여 SEO와 PWA를 최적화하는 방법을 심도 있게 살펴보았어요.<br />
핵심 내용을 다시 한번 정리해 드릴게요.
<br />
<Blockquote type="tip">
**`generateMetadata`**: 웹 페이지의 제목, 설명, 키워드, Open Graph, Twitter Card 등을 동적으로 설정하여 검색 엔진 노출과 소셜 공유 미리보기를 최적화해요.<br />
부모 레이아웃에서 기본값을 설정하고, 자식 페이지에서 필요한 부분만 오버라이딩하는 계층적 구조를 활용하는 것이 중요해요.<br />
특히 `metadataBase`와 `title.template`은 SEO 관리의 효율성을 높여준답니다.
</Blockquote>
<br />
<Blockquote type="tip">
**`generateViewport`**: 모바일 기기에서의 반응형 동작, PWA 테마 색상, 다크/라이트 모드 지원 등 사용자 경험에 직접적인 영향을 주는 뷰포트 관련 설정을 담당해요.<br />
`themeColor`와 `colorScheme`을 적절히 설정하여 PWA의 앱 같은 경험을 강화할 수 있어요.
</Blockquote>
<br />
이 두 함수는 Next.js App Router의 강력한 기능 중 하나이며, 웹사이트의 검색 엔진 최적화와 사용자 경험을 동시에 개선할 수 있는 중요한 도구예요.<br />
실무에서 이 기능들을 적극적으로 활용하여 더 나은 웹 애플리케이션을 만들어보시길 바라요!

### 1️⃣ 다음 단계: 더 나은 사용자 경험을 위해
`generateMetadata`와 `generateViewport` 외에도 Next.js App Router는 웹 성능과 개발 편의성을 위한 다양한 기능을 제공해요.<br />
예를 들어, `robots.txt`와 `sitemap.xml`을 동적으로 생성하는 방법, <LinkPreviewCard href="https://nextjs.org/docs/app/api-reference/file-conventions/metadata/robots" /> 등을 추가적으로 학습해 보시면 좋을 것 같아요.<br />
또한, Core Web Vitals 점수를 개선하기 위한 이미지 최적화, 폰트 최적화, 번들 사이즈 줄이기 등도 꾸준히 관심을 가져야 할 부분이에요.<br />
지속적인 학습과 적용을 통해 사용자에게 최고의 경험을 제공하는 웹 서비스를 만들어나가시길 응원해요!
