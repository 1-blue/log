## 🤔 CSS 변수, 왜 다시 주목해야 할까요?

### 0️⃣ 기존 CSS 관리의 어려움 🤯<br />

여러분은 CSS를 작성하면서 특정 색상이나 여백 값을 여러 곳에서 반복적으로 사용하다가, 나중에 그 값을 변경해야 할 때마다 모든 코드를 찾아 수정하느라 고생했던 경험이 있으실 거예요. 이런 방식은 개발 시간을 늘리고, 휴먼 에러의 가능성을 높이며, 코드의 일관성을 해치는 주범이 되곤 해요.<br />

특히, 웹사이트의 테마(다크 모드, 라이트 모드 등)를 변경해야 할 때마다 CSS 파일 전체를 복사하거나 복잡한 SCSS 변수 조합을 사용해야 했던 기억도 있으실 거예요. 이런 접근 방식은 확장성이 떨어지고 유지보수가 매우 어려워요.

### 1️⃣ CSS 변수의 등장과 핵심 이점 ✨<br />

CSS 변수, 또는 공식 명칭인 Custom Properties는 이러한 문제들을 해결하기 위해 등장했어요. CSS 변수는 CSS 내에서 값을 정의하고 재사용할 수 있게 해주는 강력한 도구예요. 마치 프로그래밍 언어의 변수처럼, 한 번 정의해두면 여러 곳에서 참조할 수 있고, 필요에 따라 값을 동적으로 변경할 수 있어요.<br />

<Blockquote type="info">
  **CSS 변수의 핵심 이점**
  <br />
  - **재사용성**: 반복되는 값을 한 곳에 정의하여 여러 곳에서 사용할 수 있어요.
  <br />
  - **유지보수성**: 값 변경 시 한 곳만 수정하면 되므로 유지보수가 매우 쉬워져요.
  <br />
  - **동적 제어**: JavaScript를 통해 런타임에 변수 값을 변경하여 동적인
  스타일링이 가능해요.
  <br />- **스코핑**: 캐스케이딩 규칙을 따르기 때문에 전역 및 지역 스코프를
  유연하게 관리할 수 있어요.
</Blockquote>

이러한 이점 덕분에 CSS 변수는 일관된 디자인 시스템 구축, 효율적인 테마 관리, 그리고 JavaScript와의 유기적인 상호작용을 통한 동적 UI 구현에 필수적인 요소로 자리 잡았어요.

## ⚙️ CSS 변수 심화 활용 전략

### 0️⃣ 전역/지역 스코핑과 캐스케이딩의 이해 🌍<br />

CSS 변수는 CSS의 기본 원리인 캐스케이딩(Cascading)을 그대로 따라요. 이는 변수가 선언된 위치에 따라 유효 범위(스코프)가 결정된다는 의미예요.<br />

가장 일반적인 방법은 `:root` 의사 클래스에 변수를 선언하여 전역 변수로 만드는 거예요. `:root`는 문서의 최상위 요소인 `<html>`을 의미하며, 여기에 선언된 변수는 문서 전체에서 접근할 수 있어요.<br />

```css showLineNumbers
:root {
  --primary-color: #007bff; /* 전역 기본 색상 */
  --secondary-color: #6c757d; /* 전역 보조 색상 */
  --spacing-unit: 8px; /* 전역 여백 단위 */
}

body {
  color: var(--primary-color);
  margin: var(--spacing-unit);
}
```

특정 요소나 컴포넌트 내에서 변수를 선언하면, 해당 변수는 그 요소와 그 자손에게만 유효한 지역 변수가 돼요. 이 지역 변수는 전역 변수와 이름이 같더라도 지역 스코프 내에서 전역 변수를 오버라이드(재정의)할 수 있어요.<br />

```css showLineNumbers
.card {
  --primary-color: #28a745; /* .card 내부에서만 적용되는 지역 색상 */
  border: 1px solid var(--primary-color);
  padding: calc(var(--spacing-unit) * 2);
}

.card h2 {
  color: var(--primary-color); /* .card 내부의 primary-color 적용 */
}

.footer {
  /* .card 외부이므로 전역 primary-color가 적용 */
  background-color: var(--primary-color);
}
```

이처럼 캐스케이딩 원리를 이해하면 변수의 우선순위와 유효 범위를 효과적으로 제어할 수 있어요. 상위 요소에 선언된 변수는 하위 요소에 상속되지만, 하위 요소에서 같은 이름의 변수를 선언하면 해당 지역에서만 새로운 값이 적용되는 방식이에요.<br />

### 1️⃣ 동적 테마 구현 마스터하기 🎨<br />

CSS 변수의 가장 강력한 활용 사례 중 하나는 바로 동적 테마(Dynamic Theming) 구현이에요. 다크 모드, 라이트 모드, 혹은 사용자 정의 테마를 JavaScript 없이, 혹은 최소한의 JavaScript로 구현할 수 있어요.<br />

핵심 아이디어는 `:root`에 테마 관련 변수들을 정의하고, JavaScript를 이용해 `:root` 요소의 특정 CSS 변수 값을 변경하는 거예요. 이렇게 하면 모든 하위 요소의 스타일이 자동으로 업데이트돼요.<br />

```css showLineNumbers
:root {
  --bg-color: #ffffff;
  --text-color: #333333;
  --border-color: #dddddd;
}

/* 다크 모드 클래스가 body에 추가될 때 변수 오버라이드 */
body.dark-theme {
  --bg-color: #333333;
  --text-color: #f0f0f0;
  --border-color: #555555;
}

body {
  background-color: var(--bg-color);
  color: var(--text-color);
  transition:
    background-color 0.3s ease,
    color 0.3s ease;
}

.container {
  border: 1px solid var(--border-color);
  padding: 20px;
}
```

JavaScript에서는 `document.documentElement` (즉, `<html>` 요소)의 클래스를 토글하거나, 직접 `setProperty`를 사용하여 변수 값을 변경할 수 있어요.<br />

### 2️⃣ JavaScript와 CSS 변수의 강력한 시너지 ✨<br />

CSS 변수는 JavaScript와 함께 사용될 때 그 진가를 발휘해요. JavaScript를 통해 CSS 변수의 값을 읽거나 설정함으로써, 런타임에 동적으로 UI를 제어할 수 있어요.<br />

**값 읽기:** 특정 요소에 적용된 CSS 변수 값을 읽으려면 `window.getComputedStyle()` 메서드를 사용해요. 이 메서드는 요소에 최종적으로 계산된 모든 스타일을 포함하는 객체를 반환하며, `getPropertyValue()`로 특정 변수 값을 가져올 수 있어요.<br />

```javascript showLineNumbers
const rootStyles = getComputedStyle(document.documentElement);
const primaryColor = rootStyles.getPropertyValue("--primary-color");
console.log("현재 primary-color:", primaryColor.trim()); // 공백 제거

const myElement = document.getElementById("my-element");
const elementStyles = getComputedStyle(myElement);
const elementBgColor = elementStyles.getPropertyValue("--bg-color");
console.log("my-element의 배경색:", elementBgColor.trim());
```

**값 설정:** 요소의 CSS 변수 값을 설정하려면 `element.style.setProperty()` 메서드를 사용해요. 이는 인라인 스타일로 적용되므로, 캐스케이딩 우선순위가 높아요.<br />

```javascript showLineNumbers
const myElement = document.getElementById("my-element");

// 특정 요소의 CSS 변수 변경
myElement.style.setProperty("--item-color", "purple");

// `:root` (<html>) 요소의 CSS 변수 변경
document.documentElement.style.setProperty("--primary-color", "#ff6347");
```

이러한 상호작용은 사용자의 인터랙션에 따라 실시간으로 UI의 색상, 크기, 위치 등을 변경해야 하는 복잡한 웹 애플리케이션에서 매우 유용하게 활용될 수 있어요. 예를 들어, 슬라이더 값에 따라 요소의 너비를 조절하거나, 특정 이벤트에 따라 버튼의 색상을 변경하는 등의 동적인 효과를 쉽게 구현할 수 있어요.

## 🧪 실전 코드 예시

이제 실제 코드를 통해 CSS 변수의 활용법을 자세히 살펴볼게요.

### 0️⃣ 기본 테마 설정 및 지역 변수 오버라이드 🧑‍💻<br />

먼저, 전역 변수를 설정하고 특정 컴포넌트에서 이를 오버라이드하는 예시예요. `.card` 요소 내에서 `--card-bg` 변수를 정의하고, `h2` 요소의 색상을 변경해볼게요.

```html showLineNumbers
<div class="container">
  <h1>블루의 CSS 변수 심화 가이드</h1>
  <p>전역 변수 `--primary-color`는 이 글의 기본 색상으로 사용돼요.</p>

  <div class="card">
    <h2>카드 제목</h2>
    <p>이 카드는 지역 변수 `--card-bg`를 사용해서 배경색이 달라요.</p>
    <button>자세히 보기</button>
  </div>

  <div class="another-element">
    <p>이 요소는 전역 변수를 사용해요.</p>
  </div>
</div>
```

```css showLineNumbers
:root {
  --primary-color: #007bff;
  --text-color: #333;
  --bg-color: #f8f9fa;
  --border-radius: 8px;
}

body {
  font-family: "Segoe UI", Tahoma, Geneva, Verdana, sans-serif;
  margin: 20px;
  background-color: var(--bg-color);
  color: var(--text-color);
}

h1 {
  color: var(--primary-color);
}

.card {
  --card-bg: #e2f0cb; /* 지역 변수 선언 */
  --card-text: #2c3e50;
  background-color: var(--card-bg);
  color: var(--card-text);
  border-radius: var(--border-radius);
  padding: 20px;
  margin-top: 30px;
  box-shadow: 0 4px 8px rgba(0, 0, 0, 0.1);
}

.card h2 {
  color: var(--primary-text-color, #0056b3); /* 폴백 값 사용 */
  /* `--primary-text-color`가 정의되지 않았다면 `#0056b3`를 사용해요. */
}

.another-element {
  background-color: var(--primary-color);
  color: white;
  padding: 15px;
  margin-top: 20px;
  border-radius: var(--border-radius);
}

button {
  background-color: var(--primary-color);
  color: white;
  padding: 10px 15px;
  border: none;
  border-radius: 5px;
  cursor: pointer;
  transition: background-color 0.3s ease;
}

button:hover {
  background-color: #0056b3;
}
```

위 코드에서 `.card h2`에 `var(--primary-text-color, #0056b3)`와 같이 폴백(fallback) 값을 지정한 것을 보실 수 있어요. 이는 `--primary-text-color` 변수가 정의되어 있지 않을 경우 `#0056b3`를 사용하라는 의미예요. 변수 사용의 안정성을 높이는 좋은 방법이랍니다.

### 1️⃣ JavaScript로 다크/라이트 모드 전환 구현 🌙☀️<br />

이번에는 버튼 클릭으로 웹사이트의 테마를 변경하는 예시를 보여드릴게요. HTML에 토글 버튼을 추가하고, JavaScript로 `body` 요소에 `dark-theme` 클래스를 토글하는 방식이에요.

```html showLineNumbers
<div class="theme-switcher">
  <button id="theme-toggle">테마 토글 (현재: 라이트)</button>
</div>

<div class="content">
  <p>이곳의 텍스트는 테마에 따라 색상이 변해요.</p>
  <div class="box">
    <h3>박스 제목</h3>
    <p>박스의 배경색과 텍스트 색상도 함께 변해요.</p>
  </div>
</div>
```

```css showLineNumbers
:root {
  --page-bg: #ffffff;
  --page-text: #222222;
  --box-bg: #f0f0f0;
  --box-text: #333333;
  --button-bg: #007bff;
  --button-text: #ffffff;
}

body.dark-theme {
  --page-bg: #222222;
  --page-text: #ffffff;
  --box-bg: #333333;
  --box-text: #f0f0f0;
  --button-bg: #6c757d;
  --button-text: #ffffff;
}

body {
  background-color: var(--page-bg);
  color: var(--page-text);
  transition:
    background-color 0.3s ease,
    color 0.3s ease;
  margin: 0;
  padding: 20px;
  min-height: 100vh;
  display: flex;
  flex-direction: column;
  align-items: center;
}

.theme-switcher {
  margin-bottom: 20px;
}

.content {
  text-align: center;
  max-width: 600px;
  width: 100%;
}

.box {
  background-color: var(--box-bg);
  color: var(--box-text);
  padding: 20px;
  border-radius: 10px;
  margin-top: 20px;
  transition:
    background-color 0.3s ease,
    color 0.3s ease;
}

#theme-toggle {
  background-color: var(--button-bg);
  color: var(--button-text);
  padding: 10px 20px;
  border: none;
  border-radius: 5px;
  cursor: pointer;
  font-size: 1rem;
  transition: background-color 0.3s ease;
}

#theme-toggle:hover {
  opacity: 0.9;
}
```

```javascript showLineNumbers
document.addEventListener("DOMContentLoaded", () => {
  const themeToggleBtn = document.getElementById("theme-toggle");
  const body = document.body;

  // 로컬 스토리지에서 저장된 테마 불러오기
  const savedTheme = localStorage.getItem("theme") || "light";
  if (savedTheme === "dark") {
    body.classList.add("dark-theme");
    themeToggleBtn.textContent = "테마 토글 (현재: 다크)";
  } else {
    themeToggleBtn.textContent = "테마 토글 (현재: 라이트)";
  }

  themeToggleBtn.addEventListener("click", () => {
    if (body.classList.contains("dark-theme")) {
      body.classList.remove("dark-theme");
      localStorage.setItem("theme", "light");
      themeToggleBtn.textContent = "테마 토글 (현재: 라이트)";
    } else {
      body.classList.add("dark-theme");
      localStorage.setItem("theme", "dark");
      themeToggleBtn.textContent = "테마 토글 (현재: 다크)";
    }
  });
});
```

이 예시는 CSS 변수와 JavaScript의 조합으로 얼마나 쉽게 동적 테마를 구현하고 사용자 설정을 유지할 수 있는지 보여주고 있어요. `body`에 클래스만 토글하면 CSS 변수 덕분에 모든 관련 스타일이 자동으로 변경된답니다.

### 2️⃣ 런타임에 동적으로 스타일 변경하기 ⚙️<br />

마지막으로 JavaScript를 이용해 런타임에 CSS 변수를 동적으로 제어하는 예시예요. 슬라이더 값을 조절하여 박스의 너비를 실시간으로 변경해볼게요.

```html showLineNumbers
<div class="dynamic-control">
  <label for="width-slider">박스 너비 조절:</label>
  <input type="range" id="width-slider" min="50" max="300" value="150" />
</div>
<div id="dynamic-box" class="resizable-box">
  <p>이 박스의 너비는 슬라이더로 조절돼요.</p>
</div>
```

```javascript showLineNumbers
document.addEventListener("DOMContentLoaded", () => {
  const widthSlider = document.getElementById("width-slider");
  const dynamicBox = document.getElementById("dynamic-box");

  // 초기 값 설정
  dynamicBox.style.setProperty("--box-width", `${widthSlider.value}px`);

  widthSlider.addEventListener("input", (event) => {
    const newWidth = event.target.value;
    dynamicBox.style.setProperty("--box-width", `${newWidth}px`);
  });
});
```

이처럼 `setProperty`를 활용하면 사용자의 입력이나 다른 로직에 따라 CSS 변수 값을 실시간으로 변경하여 매우 동적인 UI를 구현할 수 있어요. 이는 CSS-in-JS 라이브러리 없이도 강력한 동적 스타일링이 가능하다는 것을 보여준답니다.

## 📝 정리하며

### 0️⃣ 핵심 요약 및 실무 팁 🚀<br />

오늘 우리는 CSS 변수(Custom Properties)가 단순한 상수를 넘어, 현대 웹 개발에서 얼마나 강력하고 유연한 도구인지 살펴보았어요. 캐스케이딩을 따르는 스코핑 덕분에 전역/지역 스타일을 체계적으로 관리할 수 있고, JavaScript와의 상호작용을 통해 동적인 테마 변경 및 실시간 UI 조작이 가능해진다는 점이 핵심이에요.<br />

**실무에서 CSS 변수를 효과적으로 사용하는 팁:**<br />

- **디자인 토큰으로 활용**: 색상, 폰트 크기, 여백 등 디자인 시스템의 핵심 값을 CSS 변수로 정의하면 일관된 UI를 쉽게 유지할 수 있어요.<br />
- **폴백(Fallback) 값 활용**: `var(--my-variable, #fallback-value)`와 같이 폴백 값을 지정하여 변수가 정의되지 않았을 때의 안정성을 확보하세요.<br />
- **의미 있는 이름**: 변수 이름은 `--primary-color`처럼 의미를 명확히 담아서 다른 개발자들도 쉽게 이해할 수 있도록 해주세요.<br />
- **디버깅**: 개발자 도구에서 요소의 Computed 탭을 통해 어떤 변수 값이 최종적으로 적용되었는지 쉽게 확인할 수 있어요.<br />

### 1️⃣ 다음 단계로 나아가기 💡<br />

CSS 변수는 이제 프런트엔드 개발의 필수적인 부분이 되었어요. 여러분의 프로젝트에 CSS 변수를 적극적으로 도입하여 더 효율적이고 유지보수가 쉬운 코드를 만들어나가시길 바라요.<br />

더 나아가, CSS 변수를 활용하여 Storybook과 같은 컴포넌트 라이브러리에서 동적으로 테마를 변경하는 기능을 구현하거나, CSS-in-JS 라이브러리(Styled Components, Emotion 등)와 함께 사용하여 더욱 강력한 스타일링 경험을 만들어볼 수도 있어요. 무궁무진한 가능성이 열려 있답니다!
